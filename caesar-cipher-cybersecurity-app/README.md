# CRYPTX — Caesar Cipher

A beginner-friendly cybersecurity portfolio project built with pure HTML, CSS and JavaScript.

## Features

- Caesar Cipher encryption
- Caesar Cipher decryption
- Shift key from 0–25
- Uppercase and lowercase support
- Preserves spaces, numbers and symbols
- Copy output
- Operation history
- LocalStorage history persistence
- Responsive cybersecurity UI
- Processing animation
- Ctrl + Enter keyboard shortcut
- 100% client-side processing

## Run

Open `index.html` directly in Google Chrome.

No Node.js, PHP, database, server or installation is required.

Caesar Cipher is a classical educational cipher and is NOT suitable for protecting real secrets.
